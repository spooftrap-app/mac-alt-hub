# MacAltHub Launch Plan

## Positioning

MacAltHub is the trustworthy catalog for replacing paid Mac utilities with free, open-source, or direct-download alternatives.

## Audience

- Mac power users replacing subscriptions.
- Developers setting up new Macs.
- Students and creators who want high-quality tools without paid bundles.
- Security-conscious users who want provenance before downloading.

## Launch Checklist

- Verify catalog with `npm run verify:catalog`.
- Build the web app with `npm run build`.
- Build the macOS app with `npm run macos:build`.
- Run the ChatGPT MCP server locally with `npm run dev -w @macalthub/chatgpt`.
- Record screenshots of homepage, detail page, Mac app, and ChatGPT widget.
- Publish the website preview on Vercel.
- Share launch cards from `docs/canva-launch-pack.md`.

## First Outreach

- Reddit communities where recommendation posts are allowed.
- Hacker News "Show HN" after download verification is green.
- GitHub discussions for listed apps, only where maintainers allow showcase posts.
- Indie Mac utility newsletters and directories.

## Roadmap

- Community app submissions with review queue.
- Signed download provenance and release freshness scoring.
- Per-category sponsorships that never outrank trust metadata.
- Optional AI recommendation assistant for "I use paid app X, what should I try?"
