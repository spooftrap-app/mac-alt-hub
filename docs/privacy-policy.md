# Privacy Policy

MacAltHub is designed as a low-data utility catalog.

## Data Collected

The core catalog does not require an account and does not collect personal data.

The website may collect standard hosting logs from the deployment provider. If the optional EthicalAds slot is configured, ad delivery is handled by EthicalAds according to their publisher terms.

## Downloads

MacAltHub resolves download targets from official project pages, GitHub Releases, and Homebrew Casks. MacAltHub does not proxy installers, execute installers, or ask for credentials to download apps.

## ChatGPT App

The ChatGPT app is read-only. It searches and compares catalog entries. It does not store user prompts, create accounts, or mutate external services.

## Contact

For corrections or removal requests, open an issue in the project repository.
