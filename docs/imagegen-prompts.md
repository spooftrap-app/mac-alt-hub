# Image Generation Prompts

Use these prompts for campaign visuals or mockups when an image generation provider is configured.

## Hero Mockup

Use case: ui-mockup
Asset type: website hero image
Primary request: a polished macOS App Store-inspired catalog interface for MacAltHub showing app tiles, verified download badges, a comparison table, and a direct download button
Style/medium: realistic product UI mockup, clean native macOS aesthetic
Composition/framing: wide desktop screenshot, slight perspective, enough negative space for headline overlay
Color palette: white, graphite, macOS blue, green trust accents
Constraints: no fake brand names other than "MacAltHub"; no Discord logos; no neon; no cartoon mascot

## Social Card
